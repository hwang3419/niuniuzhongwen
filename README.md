# 🏮 马立平中文卡片识字系统 (MLP Chinese Literacy Flashcards)

专为儿童与海外华裔少儿设计的**中文卡片识字移动端 Web 应用**，紧密贴合经典**《马立平中文教材》**（低年级集中识字阶段，第一册至第三册）识字体系。支持手机端手势交互、离线 PWA、语音朗读、指尖田字格描红、趣味互动游戏与字卡打印。

---

## 🌟 核心特色与功能

### 1. 📱 移动端与全平台极致适配
- **触摸手势**：卡片支持**左右滑动切卡（Swipe Left / Right）**，**单击 3D 立体翻转**（正面识字，背面词句）。
- **移动端全屏体验**：支持 iOS Safari “添加到主屏幕” 与 Android PWA 原生安装，隐藏浏览器地址栏，沉浸式学习。
- **防止误触**：写字板专有 `touch-action: none` 保护，防止手绘时屏幕意外滚动。
- **儿童护眼大字设计**：超大楷体汉字，温润马卡龙护眼配色，支持一键切换“柔和纸张护眼模式”。

### 2. 🎴 多维字卡认读 (Flashcard Mode)
- **正面**：超大汉字、标准**米字格 / 田字格**辅助线、声调拼音（可自由显隐，支持“直映认字”进阶训练）、部首与笔画信息、发音收听按钮。
- **背面**：汉字英文释义（适合双语家庭）、**常用双字词组**（每个词均可独立点击发音）、**课文与生活经典例句**（带语音朗读）、**字源象形与趣味口诀**、**规范笔顺分解**。
- **认读追踪**：提供「🌟 认识了」与「🔁 再练练」快捷标记，配合艾宾浩斯复习机制。
- **巡航听读**：支持「▶ 自动巡航」无人值守轮播听读，适合睡前或日常磨耳朵。

### 3. ✍️ 指尖描红写字板 (Tracing & Canvas Pad)
- **米字格 / 田字格临摹**：屏幕即画板，内置浅红虚底标准楷书描红水印（可开启/关闭）。
- **仿真毛笔笔触**：真实平滑的贝塞尔曲线笔画，提供朱红、墨黑、海蓝、草绿、金黄多彩蜡笔色彩。
- **儿童友好工具**：撤销上一步、橡皮擦、一键清屏、笔顺步骤对照。

### 4. 🎮 趣味识字游戏 (Gamified Literacy)
- 🎧 **听音辨字**：纯纯磨耳朵，播放标准汉字发音，四张大字卡供选，答对奖励小星星与欢呼音效，答错温柔鼓励并跟读。
- 🧩 **看字组词 / 连连看**：挑选汉字配对成词（如“大”与“小”、“日”与“月”、“书”与“包”），锻炼词汇搭配思维。
- ⚡ **10题快速大闯关**：看拼音选字、词语挖空填空、听音辨字的综合挑战，通关发放星星金牌，附带“错题生字本”精准复习。

### 5. 🔊 纯原生离线语音与音效 (100% Offline TTS & SFX)
- **Web Speech API**：原生普通话标准发音，自动优化音调与语速（0.85x 适合幼儿语速）。
- **Web Audio API 纯代码合成音效**：清脆翻牌声、叮咚答对琴音、闪烁小星星音、胜利大欢呼号角，**完全不依赖外部音频网络文件**，离线秒加载。

### 6. 🛠️ 家长与教师管理工具
- **自定义字卡录入**：支持家长根据学校老师本周字条添加生字（汉字、拼音、词组、例句、英文）。
- **一键 A4 打印**：支持快捷打印适合剪裁的实体字卡，自带虚线剪裁边框，方便线下闪卡互动。
- **学习进度管理**：随时查看掌握率与小星星数量，支持进度重置。

## 🚀 如何运行与使用

本项目采用现代无依赖原生前端架构，无需庞大的 `node_modules` 安装或漫长编译，开箱即用：

### 方式一：直接浏览器打开
直接在浏览器中打开项目目录下的 `index.html` 即可使用。

### 方式二：使用本地静态服务器（推荐用于体验 PWA 与完整音频特性）
在终端中进入项目目录运行：

```bash
# 使用 Python 启动
python3 -m http.server 8080

# 或使用 Node.js npx serve
npx serve .
```

然后在手机或电脑浏览器中访问：`http://localhost:8080`（如果在同一局域网 Wi-Fi 下，手机可直接输入电脑的局域网 IP，如 `http://192.168.x.x:8080`）。

### 方式三：添加到手机主屏幕 (PWA)
- **iPhone / iPad (iOS Safari)**：
  1. 在 Safari 中打开网页；
  2. 点击底部中间的 **“分享”** 按钮（向上箭头的方形图标）；
  3. 滑动并选择 **“添加到主屏幕” (Add to Home Screen)**；
  4. 点击右上角 **“添加”**，桌面即生成专属应用图标，全屏无边框运行。
- **Android 设备 (Chrome / Edge)**：
  1. 在手机浏览器中打开；
  2. 点击右上角菜单（三个点），选择 **“安装应用”** 或 **“添加到主屏幕”** 即可。

## 📂 项目结构说明

```
├── index.html            # 移动端主界面与交互容器
├── manifest.json         # PWA Web App 清单文件（支持添加到主屏幕）
├── service-worker.js     # 离线缓存服务
├── icons/
│   └── icon.svg          # 高清矢量应用图标与字卡 Logo
├── css/
│   ├── style.css         # 移动端响应式样式、3D 翻转卡片、米字格排版、儿童马卡龙配色
│   └── print.css         # A4 纸打印字卡排版样式
└── js/
    ├── data.js           # 马立平教材 10 大单元 120+ 字卡核心数据库（含拼音、组词、例句、字源口诀）
    ├── audio.js          # Web Speech API 中文朗读 + Web Audio API 纯代码合成音效
    ├── storage.js        # LocalStorage 学习进度（已掌握/待复习/收藏）、自定义生字与偏好设置
    ├── canvas-writer.js  # 指尖写字板与田字格描红画布引擎
    ├── games.js          # 听音辨字、连连看组词、10题闯关互动游戏引擎
    └── app.js            # 应用程序主控制器（手势滑动、模式切换、弹窗交互）
```
